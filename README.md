# VortexPay Web

Веб-версия консольного тренажёра криптотрейдинга. Статичный сайт — без
бэкенда, без сборки, чистые HTML/CSS/JS (ES-модули).

- Котировки и свечи — реальные, напрямую с публичного REST API Binance
  (`https://api.binance.com/api/v3`), без ключа, без реальных ордеров.
- Покупка/продажа — полностью виртуальные.
- Прогресс (баланс, позиции, история сделок) хранится в `localStorage`
  браузера — на этом устройстве, между визитами.
- Свечной график и отметки сделок рисуются на `<canvas>` без сторонних
  библиотек.

## Структура

```
index.html
css/style.css
js/api.js         # клиент к Binance (klines, ticker/price, ticker/24hr)
js/storage.js      # сохранение прогресса в localStorage
js/portfolio.js     # логика виртуального портфеля: buy/sell, PnL, эквити
js/chart.js        # свечной график на canvas + отметки сделок
js/app.js         # состояние приложения, обработчики, поллинг
```

## Локальный запуск

Файлы используют ES-модули (`<script type="module">`), поэтому открыть
`index.html` двойным щелчком (`file://`) не получится — браузер заблокирует
загрузку модулей. Нужен любой локальный сервер, например:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

или расширение "Live Server" в VS Code.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки
   (файл `index.html` должен лежать в корне репозитория или в папке `docs/`).

   ```bash
   git init
   git add .
   git commit -m "VortexPay web"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```

2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a
   branch**, ветку **main** и папку **/ (root)** (или **/docs**, если файлы
   там).
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<репозиторий>/`.

Дополнительно ничего настраивать не нужно: сайт статичный, все запросы к
Binance идут прямо из браузера пользователя.

## Важное про CORS

Публичные эндпоинты Binance (`/api/v3/klines`, `/api/v3/ticker/price`,
`/api/v3/ticker/24hr`) обычно доступны для прямых запросов из браузера с
любого домена. Если после деплоя видите в консоли браузера ошибку про CORS —
это означает, что конкретный регион/провайдер блокирует запрос на уровне
сети, а не сам Binance API. В этом случае самый простой обход — небольшой
serverless-прокси (например, Cloudflare Worker в несколько строк), который
пробрасывает запрос к Binance и отдаёт тот же JSON с нужным заголовком; сайт
при этом остаётся статичным.

## Дисклеймер

Это учебный тренажёр. Он не совершает реальных сделок, не хранит и не
использует биржевые ключи и не является инвестиционной рекомендацией.
Реальный крипто-трейдинг сопряжён с высоким риском потери средств.
